A workshop can earn more by producing the more profitable product and still lose money if that decision consumes the machine needed by every other order. The decision is a vector of production quantities, rather than a ranking of individual products. Optimization starts by describing which combinations can actually be produced and what each feasible combination earns.

Consider two divisible products. Let $x_1$ and $x_2$ denote their weekly production quantities, measured in batches. One batch earns three and two monetary units, respectively. Each batch uses one hour of a finishing resource; product 1 also uses two hours of a second resource, while product 2 uses one. The weekly capacities are four and five hours. These deliberately small numbers define an original teaching construction that will recur through the next two chapters.

The model is

$$\max_{x_1,x_2}\;3x_1+2x_2 \quad\text{subject to}\quad x_1+x_2\le4,\qquad 2x_1+x_2\le5,\qquad x_1,x_2\ge0.$$

Every restriction has a physical interpretation. The first two inequalities are capacity limits; the last two specify the allowed production quantities. Profit is the objective function, and the restrictions are constraints. A vector satisfying every constraint is feasible. An optimal feasible vector has objective value at least as large as every other feasible vector. A plausible production plan need not be feasible, and a feasible plan need not be optimal.

1. Decisions, resources, and the matrix model 01:25

For $n$ products and $m$ resources, let $x\in\mathbb R^n$ be a column vector of quantities, $c\in\mathbb R^n$ the corresponding unit profits, and $b\in\mathbb R^m$ the capacities. The matrix $A\in\mathbb R^{m\times n}$ contains resource coefficients: $a_{ij}$ is the amount of resource $i$ consumed by one unit of product $j$. Here $\mathbb R$ denotes the real numbers, and $\top$ denotes transpose. Resource usage is the vector $Ax$, whose $i$th entry is $\sum_j a_{ij}x_j$.

Our chosen convention is

$$\max c^\top x\quad\text{subject to}\quad Ax\le b,\quad x\ge0.$$

Vector inequalities hold component by component. The workshop has

$$A=\begin{bmatrix}1&1\\2&1\end{bmatrix},\quad b=\begin{bmatrix}4\\5\end{bmatrix},\quad c=\begin{bmatrix}3\\2\end{bmatrix}.$$

Checking dimensions is a modeling test. The entries of $c$ are money per batch, so $c^\top x$ has money units. Each row of $A$ is hours per batch, so the corresponding entry of $Ax$ has hours. Adding a monetary cost directly to an hour limit would be a dimensional error even if a solver accepted the resulting numbers.

The first lecture reviews matrices before moving to vector spaces. A matrix is a linear map between coordinate spaces: $A$ maps production quantities to resource usage. Matrix addition requires equal dimensions, while a product $AB$ requires the number of columns of $A$ to equal the number of rows of $B$. The identity matrix $I$ leaves vectors unchanged. An upper triangular square matrix has zero entries below its diagonal; its entries above the diagonal may also be zero. This qualification matters because triangular structure concerns required zeros, not required nonzeros.

Two nonzero matrices can have zero product. For instance, $A_0=\operatorname{diag}(1,0)$ and $B_0=\operatorname{diag}(0,1)$ satisfy $A_0B_0=0$. Consequently, cancellation of matrices needs hypotheses: $AB=AC$ implies $B=C$ when $A$ is invertible, but not for arbitrary $A$. The workshop's square resource matrix happens to be invertible, yet the larger equality system used by simplex will usually be rectangular. A method that depends on an inverse of the entire constraint matrix would therefore be the wrong abstraction.

2. Linear algebra identifies choices and redundancies 44:08 · 00:29

A linear combination of vectors $v_1,\ldots,v_k$ is $\sum_i\alpha_i v_i$, with arbitrary real coefficients $\alpha_i$. Their span is the set of all such combinations. The vectors are linearly independent if $\sum_i\alpha_i v_i=0$ forces every coefficient to be zero. A basis is an independent spanning set. A spanning set can contain redundant vectors; independence is an additional requirement.

These definitions concern a vector space, a set closed under addition and scalar multiplication with the inherited vector operations. A resource-feasible set is generally not a vector space. Doubling a feasible production plan may exceed capacity, and taking its negative may violate nonnegativity. Confusing a feasible set with a vector space removes the very restrictions that make optimization interesting.

The rank of a matrix is the dimension of its column span, equivalently its row span. To solve $Mx=d$, compare the rank of $M$ with that of the augmented matrix $[M\ d]$. A solution exists exactly when $d$ belongs to the column span of $M$, which is equivalent to equal ranks. If the common rank equals the number of unknowns, the solution is unique. Otherwise any one solution $x_0$ can be shifted by a nonzero null-space vector: $M(x_0+v)=d$ whenever $Mv=0$.

For example, the equation $x_1+x_2=4$ alone does not identify production. Its solutions include $(4,0)$ and $(1,3)$, and its null space contains $(1,-1)$. Adding the independent equation $2x_1+x_2=5$ selects $(1,3)$. Adding $2x_1+2x_2=8$ instead supplies no new independent information. Changing that last right-hand side to nine creates inconsistency, since the same left-hand side would have to equal both eight and nine.

Solving a linear system is only part of solving a linear program. The workshop's optimum will make both capacities tight, but this is a conclusion to establish, not an assumption available during modeling. Another objective could prefer a point where one resource remains unused. Algebra identifies the consequences of a selected set of equalities; optimization must determine which equalities belong at the solution.

3. What makes a model linear 18:44

A linear program, abbreviated LP, has an affine objective and affine equality or inequality constraints. An affine function is a linear expression plus a constant. Adding a constant to the objective changes the reported value but does not change its optimizers. The naming conventions “standard form” and “canonical form” vary across references; we will always display the actual mathematical form.

Four modeling assumptions explain when the workshop fits an LP. Proportionality means doubling a product quantity doubles its modeled profit and resource usage. Additivity means contributions from different products sum without interaction terms. Divisibility permits fractional quantities. Deterministic coefficients mean the chosen instance treats $A$, $b$, and $c$ as known fixed values.

These assumptions should be tested separately. A setup charge violates proportionality because the first positive batch triggers a cost absent at zero. A shared chemical reaction can violate additivity. Whole machines violate divisibility. Uncertain task durations challenge deterministic capacity planning. Replacing an uncertain coefficient by its mean defines a new deterministic approximation; it does not generally preserve a reliability constraint. For example, a random one-hour or three-hour job has mean duration two, but reserving two hours does not guarantee completion within its reservation.

Nonnegativity is a modeling choice, not a universal law of physical variables. A signed power exchange, inventory deviation, or financial position can be negative. An unrestricted real variable $u$ can be represented as $u=u^+-u^-$ with $u^+,u^-\ge0$. This representation is not unique, since adding the same nonnegative number to both leaves $u$ unchanged. It preserves the original feasible decisions after projection, which is what equivalence requires.

A capacity inequality $a^\top x\le\beta$ becomes $a^\top x+s=\beta$ with a slack variable $s\ge0$. A lower bound $a^\top x\ge\beta$ becomes $a^\top x-s=\beta$ with a nonnegative surplus variable. The sign records whether an unused allowance is added or an excess above a requirement is removed. An equality can also be expressed by its two opposite inequalities. These transformations preserve feasibility; they do not determine an initial computational basis.

The modeling sequence in lecture 2 moves through problem identification, formulation, solution, validation, and implementation. Validation asks whether the mathematical restrictions correspond to the real operation. Solver success asks whether the implemented mathematical problem has been solved. The workshop needs both: verify machine-hour measurements before trusting the matrix, then verify returned quantities against that matrix before releasing a production plan.

Coverage, cutting, and flow are different constraints 41:31

In a cutting-stock model, a column can describe one feasible pattern for cutting a stock roll. Let $a_{ij}$ be the number of pieces of type $i$ produced by pattern $j$, and $x_j$ the number of stock rolls cut with that pattern. Demand $d_i$ requires $\sum_j a_{ij}x_j\ge d_i$ when overproduction is allowed, or equality when exact demand is mandatory. Whole rolls require integer $x_j$. Dropping that condition gives an LP relaxation, not an executable cutting schedule.

Minimizing waste and minimizing stock-roll count are different when surplus output is allowed. With exact output and fixed stock width, total cut length is fixed, so minimizing total input length also minimizes waste. With unrestricted overproduction, a low-waste pattern can create unwanted stock; that inventory must be priced or constrained. A model cannot decide the meaning of “waste” without the operating policy.

For staffing, a column instead indicates which time periods a shift covers. Each period's coverage must be at least its required staff count. Transportation uses balance: outgoing and incoming quantities must match supplies and demands, or obey explicitly chosen upper and lower bounds. These examples share linear algebra while representing different conservation and adequacy statements. Inspecting one row at a time prevents an accidental reversal between “at most” capacity and “at least” coverage.

4. Feasibility is an intersection of half-spaces 03:21

For a nonzero vector $a$, the equation $a^\top x=\beta$ defines a hyperplane. The vector $a$ is normal, meaning perpendicular, to all displacement directions within that hyperplane. The inequality $a^\top x\le\beta$ defines a closed half-space. “Closed” includes the boundary; strict inequality would exclude it. Ordinary LP uses non-strict inequalities, which is consequential for attainment of an optimum.

A set $P$ is convex if $\theta u+(1-\theta)v\in P$ for all $u,v\in P$ and $0\le\theta\le1$. These coefficients make a convex combination. The nonnegativity of the coefficients is essential; coefficients that merely sum to one define an affine combination, which can extend beyond the segment.

To prove that the workshop's feasible set is convex, take any feasible $u,v$. Linearity gives

$$A\bigl(\theta u+(1-\theta)v\bigr) =\theta Au+(1-\theta)Av \le\theta b+(1-\theta)b=b.$$

The same combination remains nonnegative. Every point on the segment is therefore feasible. This argument applies to any intersection of affine half-spaces. Such a finite intersection is a polyhedron; a bounded polyhedron is a polytope. A convex hull of finitely many points is a polytope, but not every polyhedron is bounded. The distinctions are developed in Boyd and Vandenberghe, §2.2.

The workshop's feasible polygon has vertices $(0,0)$, $(5/2,0)$, $(1,3)$, and $(0,4)$. A vertex, also called an extreme point, cannot be written as a strict convex combination of two distinct feasible points. In two dimensions an intersection of two independent active boundaries can define a vertex, provided that intersection satisfies every other constraint. Two parallel or coincident boundaries do not identify a unique point.

5. Why vertices are enough, and when that claim needs repair 28:16

For a nonempty bounded polyhedron, every feasible point is a convex combination of its vertices. Invoking that finite-dimensional polytope representation, write $x=\sum_k\theta_k v_k$ with nonnegative weights summing to one. Then

$$c^\top x=\sum_k\theta_k c^\top v_k \le\max_k c^\top v_k.$$

Thus a linear objective achieves its maximum at at least one vertex. The claim is existential: an optimal vertex exists. It does not say that all optimum points are vertices or that every vertex is optimal. If two distinct vertices have the same optimal value, every point on their joining segment also has that value.

Evaluating the workshop vertices gives profits $0$, $15/2$, $9$, and $8$. Therefore $(1,3)$ is optimal with profit nine. The same result follows by adding the two capacity inequalities:

$$3x_1+2x_2=(x_1+x_2)+(2x_1+x_2)\le4+5=9.$$

The proposed plan attains the bound. This second argument is a certificate: it proves that no unexamined feasible point earns more. The next chapters generalize such certificates into duality.

Boundedness of the feasible set is sufficient, not necessary, for a finite optimum. On $x\ge0$, minimizing $x$ attains zero despite an unbounded feasible ray. Maximizing $x$ on that same set is unbounded. An unbounded region alone does not settle the objective. A polyhedron containing a line can have no vertices at all; for example $\{(x_1,x_2):x_2=0\}$ has a constant zero objective but no extreme points. A more general LP theorem must therefore state additional structure, such as the pointed nonnegative equality form used below.

Infeasibility is different again. The constraints $x\ge0$ and $x\le-1$ are inconsistent, even though the latter is a less-than-or-equal inequality. The convenient initial slack solution for $Ax\le b,x\ge0$ requires $b\ge0$. Omitting that hypothesis turns a useful computational observation into a false general claim.

6. Basic feasible solutions turn geometry into algebra 06:13

Introduce workshop slacks $s_1,s_2$ and define $z=(x_1,x_2,s_1,s_2)^\top$. The equality system is

$$Mz=b,\qquad z\ge0,\qquad M=\begin{bmatrix}1&1&1&0\\2&1&0&1\end{bmatrix}.$$

More generally let $M\in\mathbb R^{m\times n}$ have row rank $m$. A basis matrix $B$ selects $m$ independent columns. Set the other, nonbasic, variables to zero and solve $Bz_B=b$ for the basic variables. The result is a basic solution. It is a basic feasible solution if $z_B\ge0$. A basic feasible solution is degenerate if at least one basic variable equals zero.

There are at most $\binom nm$ candidate bases, since a basis chooses $m$ columns from $n$. Some choices are singular, some solutions violate nonnegativity, and different bases can represent the same degenerate point. Counting bases therefore does not count distinct feasible vertices.

The correspondence with vertices can be proved directly. At a basic feasible solution, suppose $z=\theta u+(1-\theta)v$ with feasible $u,v$ and $0<\theta<1$. Every nonbasic coordinate of $z$ is zero. Nonnegativity forces the same coordinate of both $u$ and $v$ to be zero. Then $Bu_B=Bv_B=b$; invertibility gives $u_B=v_B=z_B$. Thus $u=v=z$, so $z$ is extreme.

Conversely, if the columns belonging to the positive coordinates of a feasible $z$ are dependent, choose a nonzero vector $d$ supported on those coordinates with $Md=0$. For sufficiently small $\epsilon>0$, both $z+\epsilon d$ and $z-\epsilon d$ stay nonnegative. Their midpoint is $z$, contradicting extremality. The positive-support columns are therefore independent. Extend them to a basis using full row rank; the remaining basic coordinates can be zero. This proves that every vertex in this form is a basic feasible solution, including degenerate vertices.

For the workshop, selecting the columns of $x_1,x_2$ gives $B=A$, so $x_1=1,x_2=3$ and both slacks vanish. Selecting the two slack columns gives the origin with slacks four and five. Simplex will change one basic column at a time, using objective improvement and nonnegativity to decide which adjacent basis to visit.

7. A computational check with an explicit boundary 35:15

The chapter laboratory enumerates intersections of pairs of two-dimensional constraint boundaries, filters them against every inequality, and compares objective values. It accepts finite two-dimensional inequalities and includes nonnegativity among the rows. It returns candidate vertices and performs no file or network operations. Nearly parallel rows are rejected using a determinant tolerance; floating-point tolerances are diagnostics rather than exact arithmetic proofs.

The lab independently calls SciPy's documented linear programming interface. SciPy minimizes, so the call negates the profit coefficients. Assertions compare the optimizer and objective with the hand-derived $(1,3)$ and nine. A second objective, $x_1+x_2$, yields two optimal vertices, $(1,3)$ and $(0,4)$, exposing the optimal edge. A contradictory test confirms infeasibility rather than mistaking the absence of enumerated vertices for proof of infeasibility.

Vertex enumeration is an educational algorithm for this small polygon. An unbounded polyhedron may have vertices while the objective is unbounded, and a feasible polyhedron containing a line may have no vertices. The lab's general-purpose solver, rather than the vertex list alone, classifies these cases. Larger LPs also have far too many candidate bases for indiscriminate enumeration.

Limitations and six worked problems

The model assumes divisible products, fixed coefficients, and additive economics. A correct LP solution certifies its stated objective under those restrictions. It does not establish the accuracy of measured capacities, the feasibility of fractional physical products, or the acceptability of omitted objectives such as delivery risk. Those questions change the model, not merely the optimizer's settings.

Exercise 1 — Capacity and coverage

A shift covers periods 1 and 2, and a second shift covers periods 2 and 3. The requirements are $(3,5,2)$ workers. Formulate minimum-cost staffing with shift costs $(8,7)$, and explain the integer restriction.

Worked solution

Let $u,v$ be worker counts on the two shifts. Minimize $8u+7v$ subject to $u\ge3$, $u+v\ge5$, $v\ge2$, and $u,v\in\mathbb Z_{\ge0}$. The pair $(3,2)$ satisfies every requirement and costs 38. Every feasible solution has $u\ge3,v\ge2$, so positive costs make 38 a lower bound. Here the LP optimum is already integer. That feature of this instance does not license removing integrality from arbitrary staffing models.

Exercise 2 — A redundant equality

Classify the solutions of $x_1+x_2=4$ together with $2x_1+2x_2=8$. What changes if the second right-hand side is nine?

Worked solution

With eight, both coefficient and augmented matrices have rank one. There are two unknowns, so the unconstrained solution set is the line $(t,4-t)$ for real $t$. Nonnegativity restricts it to $0\le t\le4$. With nine, subtracting twice the first equation from the second gives $0=1$. The augmented rank becomes two while coefficient rank remains one, so no solution exists.

Exercise 3 — Affine is not convex

For points $u=(0,0)$ and $v=(1,0)$, give an affine combination outside their segment and identify the missing condition.

Worked solution

The coefficients $-1$ and two sum to one, but $-u+2v=(2,0)$ lies outside the segment. A convex combination requires both coefficients nonnegative, equivalently $0\le\theta\le1$ in $\theta u+(1-\theta)v$. Summing coefficients to one by itself preserves affine structure, not membership in the convex hull.

Exercise 4 — The workshop optimum

Find every vertex of the workshop polygon and certify its optimum without relying on a drawing.

Worked solution

Intersecting both axes gives $(0,0)$. On $x_2=0$, the tighter capacity gives $x_1=5/2$; on $x_1=0$, it gives $x_2=4$. Solving both resource equalities gives $x_1=1,x_2=3$. Their profits are $0,15/2,8,9$. Adding the two inequalities proves profit is at most nine for every feasible point. Equality in the sum requires equality in both nonnegative slacks, whose unique intersection is $(1,3)$. Thus the optimum is unique.

Exercise 5 — Feasibility and boundedness

Give one infeasible LP using only less-than-or-equal rows, and one LP with an unbounded feasible set and a finite attained optimum.

Worked solution

The constraints $-x\le0$ and $x\le-1$ require both $x\ge0$ and $x\le-1$, so their intersection is empty. The signs of the inequality symbols do not ensure feasibility. For the second request, minimize $x$ subject to $-x\le0$. The feasible ray is unbounded, but every feasible objective is nonnegative and $x=0$ attains zero. Maximizing that same objective would instead be unbounded.

Exercise 6 — Degeneracy is not nonexistence

For $z_1+z_2=0$ with $z\ge0$, list its basic feasible solutions and determine whether its only feasible point is a vertex.

Worked solution

The coefficient matrix is $[1\ 1]$ with rank one. Choosing either column as the basis sets the other variable to zero and solves the remaining variable as zero. Both bases represent $(0,0)$, and both are degenerate because the basic variable vanishes. Nonnegativity and the equality imply that no other feasible point exists, so $(0,0)$ is extreme. Degeneracy concerns basis representation and zero basic coordinates; it does not imply infeasibility or the absence of an optimum.

"""Two-dimensional LP vertices checked against an independent LP solver."""
from itertools import combinations
import json

import numpy as np
from scipy.optimize import linprog


def vertices_2d(A, b, tolerance=1e-10):
    """Return feasible pairwise boundary intersections; no boundedness claim."""
    A, b = np.asarray(A, float), np.asarray(b, float)
    if A.ndim != 2 or A.shape[1] != 2 or b.shape != (len(A),):
        raise ValueError("Expected A of shape (m, 2) and b of shape (m,)")
    if not np.isfinite(A).all() or not np.isfinite(b).all():
        raise ValueError("Coefficients must be finite")
    points = []
    for indices in combinations(range(len(A)), 2):
        rows = list(indices)
        if abs(np.linalg.det(A[rows])) <= tolerance:
            continue
        point = np.linalg.solve(A[rows], b[rows])
        if np.all(A @ point <= b + tolerance):
            if not any(np.allclose(point, old) for old in points):
                points.append(point)
    return np.array(points).reshape(-1, 2)


def main():
    A = np.array([[1, 1], [2, 1], [-1, 0], [0, -1]], float)
    b = np.array([4, 5, 0, 0], float)
    c = np.array([3, 2], float)
    vertices = vertices_2d(A, b)
    profits = vertices @ c
    best = vertices[np.argmax(profits)]
    reference = linprog(-c, A_ub=A[:2], b_ub=b[:2], method="highs")
    assert len(vertices) == 4
    assert np.allclose(best, [1, 3])
    assert np.isclose(profits.max(), 9)
    assert reference.success and np.allclose(reference.x, best)
    assert np.isclose(-reference.fun, 9)
    edge_values = vertices @ np.ones(2)
    assert np.count_nonzero(np.isclose(edge_values, 4)) == 2
    infeasible = linprog([1], A_ub=[[1]], b_ub=[-1], method="highs")
    assert infeasible.status == 2
    unbounded = linprog([-1], method="highs")
    assert unbounded.status == 3
    print(json.dumps({"vertices": vertices.tolist(), "optimum": best.tolist(),
                      "profit": 9, "optimal_edge_vertices": 2,
                      "infeasible_status": infeasible.status,
                      "unbounded_status": unbounded.status}))


if __name__ == "__main__":
    main()
