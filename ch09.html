09. Equality constraints, KKT conditions, and sensitivity

An unconstrained optimizer can reduce calibration error by changing two parameters in a direction that violates a conservation law. A zero gradient is no longer the right requirement. The question is whether any feasible change reduces the objective. Lagrange multipliers and the Karush–Kuhn–Tucker conditions describe how constraint normals block otherwise improving directions.

Our original running allocation model minimizes squared deviation from a preferred operating point. We first impose an equality and then replace it with a capacity inequality. This exposes three distinctions: equality multipliers can have either sign; active inequality multipliers may be zero; and local stationarity becomes a global certificate only under additional structure.

1. Eliminating an equality must preserve its entire domain 17:10

Consider $\min x^2+y^2+z^2$ subject to $x+y+2z=12$, with unrestricted real variables. The objective penalizes large allocations and the equality imposes a fixed weighted total. Direct substitution gives $z=(12-x-y)/2$, so the reduced objective is

$$\phi(x,y)=x^2+y^2+\tfrac14(12-x-y)^2.$$

Its gradient equations are $2x-(12-x-y)/2=0$ and $2y-(12-x-y)/2=0$. Subtracting gives $x=y$, and substitution yields $x=y=2$, $z=4$. The objective is 24. The reduced Hessian is $\begin{bmatrix}5/2&1/2\\1/2&5/2\end{bmatrix}$, whose eigenvalues are 2 and 3. It is positive definite everywhere, so the reduced problem is strictly convex and this solution is its unique global minimum.

Substitution is exact here because every real $(x,y)$ yields one feasible $z$, and every feasible triple has this representation. For a nonlinear equality, one formula can lose branches or introduce a restricted parameter domain. Replacing $x^2+y^2=1$ by $y=\sqrt{1-x^2}$ retains only the upper semicircle and requires $-1\le x\le1$. Applying an unconstrained theorem to all real $x$ would solve neither the original circle nor the correctly reduced problem.

A local implicit-function representation also requires a nonzero appropriate derivative. Having fewer equality equations than variables does not by itself guarantee a global elimination formula. Constraint dependence, singular points, and disconnected components require separate attention.

2. Lagrange multipliers encode the normal-space condition 24:31

Let $x\in\mathbb R^n$, let $f(x)$ be differentiable, and impose differentiable equalities $h(x)=0$ with $h:\mathbb R^n\to\mathbb R^p$. The Jacobian $J_h(x)$ has row $j$ equal to $\nabla h_j(x)^\top$. At a regular point, these rows are linearly independent. A first-order feasible tangent direction $d$ satisfies $J_h(x)d=0$.

At a regular local minimizer, the objective derivative must vanish along every feasible tangent direction. Both directions along a smooth feasible curve are locally available, so a nonzero tangent derivative would permit improvement in one orientation. Linear algebra then says that $\nabla f(x_*)$ lies in the row space of the equality Jacobian: the orthogonal complement of its null space.

Introduce unrestricted multipliers $\nu\in\mathbb R^p$ and define the Lagrangian

$$L(x,\nu)=f(x)+\nu^\top h(x).$$

The first-order equations are

$$\nabla_x L(x_*,\nu_*)=\nabla f(x_*)+J_h(x_*)^\top\nu_*=0, \qquad h(x_*)=0.$$

The sign convention is fixed by this displayed definition. Writing $f-\nu^\top h$ would reverse the multiplier signs while describing the same primal stationarity. Equality multipliers have no nonnegativity restriction because an equality's normal may be used in either orientation.

For the allocation example, take $h=x+y+2z-12$. Stationarity gives $2x+\nu=0$, $2y+\nu=0$, and $2z+2\nu=0$. Thus $x=y=-\nu/2$ and $z=-\nu$. The equality gives $-3\nu=12$, so $\nu=-4$ and the same solution $(2,2,4)$ follows.

The Lagrangian is not jointly minimized over primal and multiplier variables

The multiplier equations enforce the original constraints. They do not convert the constrained problem into ordinary unconstrained minimization of $L$ over $(x,\nu)$. At any infeasible $x$ with $h(x)\ne0$, choosing $\nu=-t h(x)$ sends $\nu^\top h(x)$ to $-\infty$ as $t\to\infty$. Joint minimization would therefore encourage unbounded multiplier behavior rather than enforce feasibility.

Even at a correct solution, the Lagrangian's full Hessian in $(x,\nu)$ is generally indefinite. Its multiplier-multiplier block is zero. A vector supported only on nonzero multiplier coordinates gives zero quadratic form, already ruling out positive definiteness. The stationarity equations form a constrained or saddle system, not a joint-minimum test.

For the equality allocation example, the full symmetric KKT matrix is

$$\begin{bmatrix}2I_3&a\\a^\top&0\end{bmatrix}, \qquad a=(1,1,2)^\top.$$

It has both positive and negative eigenvalues despite the primal problem's unique minimum. Demanding positive definiteness of this bordered matrix would reject a valid constrained minimizer. This is a consequential difference between the full stationarity system and curvature along feasible directions.

3. Second-order tests use the Lagrangian on the tangent space 36:46

For twice continuously differentiable equalities, let $x(t)$ be a feasible curve with $x(0)=x_*$ and $x'(0)=d$. Differentiating $h(x(t))=0$ twice gives $J_hx''(0)$ plus the vector of constraint-curvature terms $d^\top\nabla^2h_jd$ equal to zero. Meanwhile,

$$\frac{d^2}{dt^2}f(x(t))\bigg|_{t=0} =d^\top\nabla^2 f(x_*)d+\nabla f(x_*)^\top x''(0).$$

Substitute $\nabla f=-J_h^\top\nu_*$ and the differentiated feasibility relation. The expression becomes $d^\top\nabla^2_{xx}L(x_*,\nu_*)d$. Constraint curvature contributes through the multipliers. The objective Hessian alone can miss it.

At a regular constrained local minimum this quadratic form is nonnegative for all tangent directions. Positive definiteness on every nonzero tangent direction, together with stationarity and regularity, is a sufficient condition for a strict local minimum. A convenient computation chooses columns of a matrix $Z$ spanning $\ker J_h$ and tests the reduced Hessian $Z^\top\nabla^2_{xx}LZ$. Its dimension is the number of locally free directions.

For a concrete curved constraint, minimize $y$ subject to $h(x,y)=x^2-y=0$. Feasibility reduces the objective to $x^2$, so $(0,0)$ is a strict constrained minimum. The objective Hessian is zero everywhere and supplies no useful curvature. With $L=y+\nu(x^2-y)$, stationarity gives $\nu=1$. At the origin the tangent directions have form $(d_x,0)$, and the Lagrangian curvature is $2d_x^2>0$ for nonzero tangent displacements. This recovers the missing geometric effect.

Regularity is not optional in the multiplier necessity claim. Minimize $x$ subject to $x^2=0$. The only feasible point is zero, so it is a global minimizer. But stationarity would require $1+\nu(2x)=0$, impossible at zero. The constraint gradient vanishes there. The geometric feasible set is valid; its chosen equation has a singular first-order description.

4. Inequalities add multiplier signs and complementary slackness 00:19

Now consider

$$\min f(x)\quad\text{subject to}\quad g_i(x)\le0\ (i=1,\ldots,m),\qquad h_j(x)=0\ (j=1,\ldots,p).$$

Define $L(x,\lambda,\nu)=f(x)+\sum_i\lambda_i g_i(x)+\sum_j\nu_jh_j(x)$. The Karush–Kuhn–Tucker conditions, KKT, consist of four requirements:

  1. Primal feasibility: $g_i(x_*)\le0$ and $h_j(x_*)=0$.
  2. Dual feasibility: $\lambda_i\ge0$, with equality multipliers $\nu_j$ unrestricted.
  3. Stationarity: $\nabla f(x_*)+\sum_i\lambda_i\nabla g_i(x_*)+\sum_j\nu_j\nabla h_j(x_*)=0$.
  4. Complementary slackness: $\lambda_i g_i(x_*)=0$ for each inequality.

An inequality is active if $g_i(x_*)=0$ and inactive if it is strictly negative. Complementary slackness forces the multiplier of an inactive inequality to vanish. It does not force an active multiplier to be positive. For $\min x^2$ subject to $-x\le0$, the optimum zero is active but stationarity gives $\lambda=0$. Activity concerns a geometric equality; a positive multiplier concerns a nonzero marginal effect under appropriate sensitivity assumptions.

The multiplier sign reflects the inequality convention. For a minimization problem with $g_i\le0$, nonnegative multipliers ensure $L(x,\lambda,\nu)\le f(x)$ at every feasible point. This lower-bound property connects KKT with duality. If a constraint is written as $g_i\ge0$, either negate the function or change the associated sign rule consistently. Signs cannot be transferred from a maximization tableau by memory.

Introducing squared slacks $g_i(x)+s_i^2=0$ is an algebraic way to represent inequality feasibility. Differentiation gives $2\lambda_i s_i=0$, suggesting complementarity. It does not by itself prove multiplier nonnegativity, constraint qualification, or sufficiency of stationarity. At $s_i=0$, the derivative with respect to the slack vanishes, which can create singular descriptions. The four explicit KKT requirements remain the reliable contract.

5. Constraint qualification licenses necessity; convexity licenses sufficiency 22:17

For differentiable nonlinear constraints, a local optimum need not satisfy KKT without a constraint qualification, a regularity assumption on how the constraints describe feasible directions. One sufficient condition is linear independence of all equality gradients and active inequality gradients at the optimum, commonly called LICQ. It ensures that the first-order normal representation is valid. Other qualifications are weaker and can apply when LICQ fails.

The earlier example $\min x$ subject to $x^2\le0$ shows the issue with inequalities. Its sole feasible point is zero, but stationarity $1+2\lambda x=0$ cannot hold. The gradient of the active inequality vanishes. This is not evidence that the problem lacks an optimum; it is evidence that an unqualified multiplier necessity theorem was misapplied.

KKT is generally not sufficient for local optimality. Minimize $-x^2$ subject to $-1\le x\le1$. At zero both inequalities are inactive, their multipliers can be zero, and the objective derivative is zero. All KKT conditions hold, yet zero is a strict local maximum. The equations identify candidate stationary structure, not the desired curvature.

For a convex optimization problem, take a convex differentiable objective, convex differentiable inequality functions, and affine equalities, all on an appropriate convex domain. Any feasible KKT point is globally optimal. To prove it, fix its multipliers. Nonnegative weighted sums preserve convexity, so $L(\cdot,\lambda_*,\nu_*)$ is convex. Stationarity makes $x_*$ a global minimizer of that Lagrangian. For every feasible $x$,

$$f(x)\ge L(x,\lambda_*,\nu_*) \ge L(x_*,\lambda_*,\nu_*)=f(x_*).$$

The final equality uses feasibility and complementary slackness. This is a complete global certificate. It requires no positive-definite Hessian, no unique optimum, and no additional constraint qualification once a KKT point has actually been found.

Constraint qualifications matter again when asking whether an optimum has multipliers at all. In convex problems, Slater's condition requires a feasible point satisfying all inequality constraints strictly, with affine equalities satisfied exactly, under the usual domain assumptions. It supplies strong duality and multiplier existence for a finite attained optimum in the standard setting. Boyd and Vandenberghe, §5.5.3, printed pp. 243–244 separate these necessity and sufficiency claims explicitly.

6. An active-set calculation gives a verifiable allocation 50:25

Minimize $f(x,y)=(x-2)^2+(y-3)^2$ subject to $x+y\le3$, $-2x+y\le2$, and $x,y\ge0$. The preferred unconstrained point $(2,3)$ violates the first capacity. Introduce multipliers $\lambda_1,\lambda_2$ for the displayed capacities and $\alpha,\beta$ for $-x\le0,-y\le0$.

At a candidate with positive $x,y$, complementarity gives $\alpha=\beta=0$. Suppose the first capacity binds and the second is inactive. The equations become $2(x-2)+\lambda_1=0$, $2(y-3)+\lambda_1=0$, and $x+y=3$. Adding the first two gives $2(3-5)+2\lambda_1=0$, so $\lambda_1=2$. Then $x=1$ and $y=2$.

Check every condition rather than accepting the algebraic root. The second capacity has value $-2(1)+2=0<2$, so it is indeed inactive and $\lambda_2=0$. Both variables are positive, so lower-bound multipliers vanish. The first multiplier is nonnegative. The loss is $1+1=2$. The convex global certificate applies, and strict convexity of this objective makes the optimum unique.

A direct certificate is also available. With the accepted multipliers, $L=f+2(x+y-3)$ expands to $(x-1)^2+(y-2)^2+2$. Its minimum over all real pairs is 2. Feasible points satisfy $f\ge L$, and $(1,2)$ attains equality. This independently checks both the answer and the multiplier sign.

Enumerating active sets can solve small problems, but the number of subsets grows exponentially. Degenerate constraints can create multiple descriptions of the same point. A candidate must pass primal feasibility, multiplier signs, and stationarity; solving equalities alone can produce infeasible points or negative multipliers. Larger numerical methods manage this structure without listing every subset explicitly.

7. A multiplier is a local value derivative under regularity 50:00

For an equality $h(x)=b$, define the optimal value $v(b)$ and use $L=f+\nu(h-b)$. Assume a smoothly varying optimizer and multiplier exist nearby. Differentiating feasibility gives $J_hx'(b)=1$ for a scalar right-hand side. Differentiating the objective and using stationarity gives

$$v'(b)=\nabla f(x(b))^\top x'(b) =-\nu(b)J_hx'(b)=-\nu(b).$$

For the equality allocation problem with right-hand side $b$, the solution is $(b/6,b/6,b/3)$. Its value is $v(b)=b^2/6$, so $v'(12)=4$. The multiplier at 12 is $-4$, confirming the sign. Increasing an equality right-hand side is not inherently a relaxation: feasible sets for different equality values are generally not nested.

For the inequality $g_i(x)\le b_i$, increasing $b_i$ enlarges the feasible set and cannot increase a minimization optimum. Under differentiable sensitivity, $\partial v/\partial b_i=-\lambda_i\le0$. At active-set changes, the value function may be nondifferentiable and multipliers can instead support directional or subgradient statements. A shadow price is not permission to extrapolate a local derivative over arbitrarily large resource changes. Boyd and Vandenberghe, §5.6.3 state the differentiability qualification.

8. Executable certificates and limits

The chapter lab enumerates independent active sets for a tiny squared-distance quadratic program, solves the associated linear KKT systems, and filters candidates by feasibility and multiplier signs. It checks the allocation $(1,2)$, multipliers $(2,0,0,0)$, loss 2, stationarity, and complementary slackness. Inputs must be finite arrays of compatible dimensions; singular candidate systems are skipped. This is an educational finite-instance procedure, not a general nonlinear solver.

The lab independently solves the four-by-four bordered equality system and obtains $(2,2,4,-4)$. It verifies that the matrix has eigenvalues of both signs and that the value-function finite difference is 4. These checks establish the stated examples. They do not test all constraint qualifications or provide a general second-order inequality-constrained theorem; that theorem requires curvature on an appropriate critical cone, beyond simply testing the full Hessian.

  4. Give an active constraint with zero multiplier and an optimum at which no KKT multiplier exists.
  5. Verify all KKT conditions and a global certificate for the capacity allocation $(1,2)$.
  6. Derive the equality value function for right-hand side $b$ and compare its derivative with the multiplier. Explain why equality changes are not automatically relaxations.
Fully worked solutions

  1. Substitute $z=(12-x-y)/2$. The reduced gradient equations imply $x=y=2$, hence $z=4$ and objective 24. The reduced Hessian has positive eigenvalues 2 and 3 everywhere, so its objective is strictly convex. Every feasible triple corresponds to one reduced pair, proving globality and uniqueness for the original problem. Alternatively Cauchy–Schwarz gives $(x+y+2z)^2\le6(x^2+y^2+z^2)$, so the objective is at least $144/6=24$; equality holds when $(x,y,z)$ is proportional to $(1,1,2)$, yielding the same triple.

  2. The full matrix includes derivatives with respect to free equality multipliers and has a zero multiplier-multiplier block. A vector with only multiplier entries has zero quadratic form, ruling out positive definiteness. In the worked example eigenvalues of both signs appear. Feasible primal displacements are restricted by the equality Jacobian, and only the Lagrangian curvature on that tangent subspace classifies the constrained minimum.

  3. With $L=y+\nu(x^2-y)$, stationarity at the origin gives $\nu=1$. The equality gradient is $(0,-1)$, so tangent vectors are $(d_x,0)$. The primal Hessian of $L$ is $\operatorname{diag}(2,0)$, producing tangent curvature $2d_x^2>0$. Direct substitution $y=x^2$ proves the same strict constrained minimum. The zero objective Hessian would have missed the constraint curvature.

  4. For $\min x^2$ subject to $-x\le0$, zero is active and stationarity gives multiplier zero. For $\min x$ subject to $x^2\le0$, zero is the only feasible point, but stationarity would require $1+\lambda(0)=0$. There is no multiplier because the active constraint's gradient vanishes. Complementarity's converse and unqualified necessity both fail in these examples for different reasons.

  5. At $(1,2)$, the capacity residuals are zero and $-2$, and lower-bound residuals are $-1,-2$. Set multipliers to $(2,0,0,0)$. The objective gradient is $(-2,-2)$, canceled by $2(1,1)$. All products of multiplier and residual vanish, all multipliers are nonnegative, and feasibility holds. The Lagrangian equals $(x-1)^2+(y-2)^2+2$, so it lower-bounds every feasible objective by 2. The candidate attains it and is uniquely optimal by strict convexity.

  6. The equality solution is proportional to $(1,1,2)$: $(b/6,b/6,b/3)$. Squaring and summing gives $v(b)=b^2/6$. Thus $v'(b)=b/3$ and at 12 it is 4. Stationarity gives $\nu=-b/3$, so $v'=-\nu$. An equality fixes a level surface; moving that surface replaces the feasible set rather than necessarily enlarging it. An inequality upper bound instead has nested feasible sets as the bound increases.

"""KKT equations verified against all active sets of a small convex QP."""
from itertools import combinations

import numpy as np


def active_set_solutions(center, matrix, bounds, tolerance=1e-9):
    """Solve min ||x-center||^2 subject to matrix @ x <= bounds.

    Enumerates independent active sets up to parameter dimension; finite,
    tiny teaching instances only. Returns feasible KKT candidate triples.
    """
    center = np.asarray(center, float)
    matrix = np.asarray(matrix, float)
    bounds = np.asarray(bounds, float)
    n = len(center)
    if (center.ndim != 1 or matrix.ndim != 2 or matrix.shape[1] != n
            or bounds.shape != (len(matrix),)
            or not all(np.isfinite(a).all() for a in (center, matrix, bounds))):
        raise ValueError("finite arrays with compatible dimensions required")
    candidates = []
    for size in range(min(n, len(matrix)) + 1):
        for active in combinations(range(len(matrix)), size):
            selected = matrix[list(active)]
            kkt = np.block([[2 * np.eye(n), selected.T],
                            [selected, np.zeros((size, size))]])
            rhs = np.r_[2 * center, bounds[list(active)]]
            try:
                answer = np.linalg.solve(kkt, rhs)
            except np.linalg.LinAlgError:
                continue
            x, values = answer[:n], answer[n:]
            if np.all(matrix @ x <= bounds + tolerance) and np.all(values >= -tolerance):
                multipliers = np.zeros(len(matrix))
                multipliers[list(active)] = values
                candidates.append((x, multipliers, active))
    return candidates


if __name__ == "__main__":
    matrix = np.array([[1, 1], [-2, 1], [-1, 0], [0, -1]], float)
    bounds = np.array([3, 2, 0, 0], float)
    candidates = active_set_solutions([2, 3], matrix, bounds)
    assert candidates
    for x, multipliers, active in candidates:
        assert np.allclose(x, [1, 2])
        assert np.allclose(multipliers, [2, 0, 0, 0])
        assert np.allclose(2 * (x - [2, 3]) + matrix.T @ multipliers, 0)
        assert np.allclose(multipliers * (matrix @ x - bounds), 0)
        assert np.isclose(np.sum((x - [2, 3]) ** 2), 2)
    a = np.array([[1.0, 1.0, 2.0]])
    bordered = np.block([[2 * np.eye(3), a.T], [a, np.zeros((1, 1))]])
    answer = np.linalg.solve(bordered, [0, 0, 0, 12])
    assert np.allclose(answer, [2, 2, 4, -4])
    eigenvalues = np.linalg.eigvalsh(bordered)
    assert eigenvalues.min() < 0 < eigenvalues.max()
    epsilon = 1e-5
    value = lambda b: b * b / 6
    sensitivity = (value(12 + epsilon) - value(12 - epsilon)) / (2 * epsilon)
    assert np.isclose(sensitivity, 4)
    print("inequality optimum=(1,2), loss=2, lambda=(2,0,0,0)")
    print("equality optimum=(2,2,4), objective=24, multiplier=-4")
