08. Stationary points, curvature, and global optimality

A calibration program reports that every first derivative is zero. That can mean it has found the best calibration, a local maximum of the error, or a saddle from which error decreases in some directions. The same stopping message can describe all three. Before choosing a numerical algorithm, we need to know what its derivative diagnostics actually certify.

Consider a scalar parameter $x$ whose measurement depends on $x^2$. Matching a unit measurement gives the original teaching loss $q(x)=(x^2-1)^2$. It has an ambiguity between positive and negative calibration. A second construction uses two parameters $u,v$ and two residuals: $u+v-1$ and $u-v$. Its weighted loss is $f(u,v)=(u+v-1)^2+2(u-v)^2$. These small models let us contrast nonconvex ambiguity with a unique convex solution without confusing solver behavior with measurement information.

1. Local and global questions have different quantifiers 13:55

Let $D\subseteq\mathbb R^n$ be a domain and let $f:D\to\mathbb R$ be an objective to minimize. A point $x_*\in D$ is a local minimizer if there exists a radius $r>0$ such that $f(x_*)\le f(x)$ for every feasible $x$ with $\|x-x_*\|_2<r$. Here $\|z\|_2=(\sum_i z_i^2)^{1/2}$ is Euclidean length. A global minimizer satisfies the inequality for every $x\in D$. A strict local minimizer makes it strict for all nearby distinct points.

The existence of one neighborhood is weaker than a claim about the whole domain. A local calibration can resist every sufficiently small perturbation and still be worse than another distant calibration. A global minimizer is necessarily local, but a local minimizer need not be global. Replacing $f$ with $-f$ converts minimization statements into maximization statements.

For $q(x)=(x^2-1)^2$, nonnegativity gives $q(x)\ge0$ everywhere. Both $x=1$ and $x=-1$ attain zero, so both are global minima. The loss cannot tell the sign apart. This is an identification issue in the model, not an optimization defect. Adding a sign convention or another measurement would change the feasible domain or loss and could remove the ambiguity.

An objective can have a finite infimum without attaining it. On the whole real line, $f(x)=e^x$ has infimum zero but no finite minimizing point. On the open interval $(0,1)$, $f(x)=x$ has the same problem. By contrast, a continuous function on a nonempty compact set attains both minimum and maximum. Compactness combines closedness and boundedness in finite-dimensional Euclidean space. Neither a derivative calculation nor strict convexity alone supplies this existence guarantee.

Domains matter at endpoints. Minimizing $x$ on $[0,1]$ gives the endpoint zero, even though the derivative is one. The absence of constraints in a displayed problem often means the entire parameter space, but a physical range such as $[0,1]$ is itself a constraint. An interior theorem cannot silently be applied to a boundary optimum.

2. Vanishing derivatives are necessary only under stated conditions 20:23

Suppose a scalar function is differentiable at an interior local minimum $x_*$. For sufficiently small $h$, the difference $f(x_*+h)-f(x_*)$ is nonnegative. Dividing by positive $h$ gives a nonnegative quotient, whereas dividing by negative $h$ gives a nonpositive quotient. If the two-sided derivative exists, its left and right limits agree; their only common permitted value is zero. Thus $f'(x_*)=0$.

A stationary point is an interior point where the derivative, or multivariable gradient, vanishes. Stationarity is a property defined by derivatives. It is not a synonym for maximum or minimum. For $q$, differentiation gives $q'(x)=4x(x^2-1)$, so the stationary points are $-1,0,1$. At zero the loss is one, and every sufficiently small nonzero $x$ lowers it because $q(x)-q(0)=-2x^2+x^4<0$ for $0<|x|<\sqrt2$. The stationary calibration zero is a strict local maximum.

The differentiability hypothesis is essential. The function $|x|$ has a strict global minimum at zero but no ordinary derivative there. Its left derivative is $-1$ and right derivative is 1, exactly the one-sided pattern that blocks descent. Nonsmooth optimality uses other notions, such as subgradients for convex functions. Declaring the minimizer absent because the ordinary derivative fails would discard the right answer.

An inflection point concerns a change of curvature, rather than a horizontal tangent. For $x^3$, zero is a stationary inflection point. For $x^3+x$, zero is still an inflection point because the second derivative $6x$ changes sign, but the first derivative there is one. The first-order necessary condition for an interior extremum does not claim that every inflection point is stationary.

For several variables, let the gradient $\nabla f(x)$ be the column vector of first partial derivatives. If $f$ is differentiable near an interior local minimum $x_*$, restricting $f$ to each coordinate line yields zero partial derivatives, hence $\nabla f(x_*)=0$. Equivalently, if the gradient is nonzero, choose direction $d=-\nabla f(x_*)$. Differentiability gives

$$f(x_*+\alpha d)-f(x_*) =\alpha\nabla f(x_*)^\top d+o(\alpha) =-\alpha\|\nabla f(x_*)\|_2^2+o(\alpha).$$

For sufficiently small positive $\alpha$, the negative linear term dominates. This produces a nearby improvement, contradicting local minimality. The notation $o(\alpha)$ means a remainder whose ratio to $\alpha$ tends to zero. It is the comparison of orders, rather than simply discarding the remainder, that licenses the conclusion.

3. Taylor expansion classifies nondegenerate stationary points 26:15

For a twice continuously differentiable scalar function near $x_*$,

$$f(x_*+h)=f(x_*)+f'(x_*)h+\tfrac12 f''(x_*)h^2+o(h^2).$$

At a stationary point, the linear term vanishes. If $f''(x_*)>0$, the positive quadratic term dominates the smaller remainder for small nonzero $h$, proving a strict local minimum. If it is negative, the same argument proves a strict local maximum. If it is zero, the test is inconclusive. Inconclusive is a statement about the test, not a classification of the point.

For $q$, $q''(x)=12x^2-4$. Its values at $-1,0,1$ are $8,-4,8$. These agree with the direct nonnegativity proof of the two minima and the local-maximum calculation at zero. The derivative test is local; the global-minimum certificate came from the square's nonnegativity.

When the first nonzero derivative at a stationary point has order $k\ge2$, a sufficiently smooth Taylor expansion gives $f(x_*+h)-f(x_*)=f^{(k)}(x_*)h^k/k!+o(|h|^k)$. If $k$ is even, the derivative's sign determines a strict local minimum or maximum. If $k$ is odd, the leading term changes sign across zero, proving that the point is neither a local minimum nor a local maximum.

For $x^4$, the first three derivatives vanish at zero and the fourth derivative is 24. It has a strict minimum even though the second-derivative test is inconclusive. For $x^3$, the first nonzero derivative has odd order three, and its values on the two sides have opposite signs. An odd first nonzero derivative therefore gives a definite non-extremum conclusion; it is stronger than merely saying “nothing can be determined.”

Some smooth functions have every derivative zero at a point, so a search for a first nonzero derivative need not terminate. More generally, numerical derivatives near a flat point can be dominated by rounding or measurement noise. A symbolic zero, a small computed derivative, and an experimentally unresolved derivative have different evidentiary status.

4. The Hessian is a quadratic form in every direction 12:42

The Hessian $H(x)=\nabla^2 f(x)$ is the matrix of second partial derivatives. Continuous second partial derivatives make it symmetric. For a displacement vector $h\in\mathbb R^n$, Taylor expansion at a stationary point gives

$$f(x_*+h)-f(x_*)=\tfrac12h^\top H(x_*)h+o(\|h\|_2^2).$$

A symmetric matrix $H$ is positive definite if $h^\top Hh>0$ for every nonzero $h$, and positive semidefinite if the expression is nonnegative. Negative definiteness and semidefiniteness reverse the signs. Indefinite means there are directions with positive and negative quadratic-form values.

The all-directions quantifier matters. A positive diagonal is insufficient for positive definiteness. For $H=\begin{bmatrix}1&2\\2&1\end{bmatrix}$, the quadratic form along $(1,1)$ is positive and along $(1,-1)$ negative. Cross terms can create a direction of descent that coordinate-wise checks miss.

If $H(x_*)$ is positive definite, its smallest eigenvalue $\lambda_{\min}$ is positive and $h^\top Hh\ge\lambda_{\min}\|h\|_2^2$. The remainder is smaller than, for example, $(\lambda_{\min}/4)\|h\|_2^2$ sufficiently near the point. Consequently the total difference is positive for every sufficiently small nonzero displacement. This supplies the uniform bound needed to prove a strict local minimum, rather than assuming that each individual Hessian entry retains a convenient sign.

An indefinite Hessian at a stationary point proves a saddle point: choose eigenvectors with positive and negative eigenvalues and take sufficiently small displacements along each. The objective lies both above and below its stationary value in every sufficiently small neighborhood. A negative-definite Hessian similarly proves a strict local maximum.

Semidefiniteness at a stationary point is necessary for a twice-differentiable local minimum, but is not sufficient. Restricting to a line in any direction shows that $h^\top H(x_*)h$ cannot be negative at a local minimum. Zero-curvature directions remain undecided. The three functions $u^4+v^4$, $-u^4-v^4$, and $u^4-v^4$ all have zero Hessian at the origin, yet exhibit a strict minimum, strict maximum, and saddle, respectively.

Leading principal minors cannot be used carelessly 30:17

For a symmetric matrix, Sylvester's criterion states that positive leading principal minors characterize positive definiteness. A leading principal minor is the determinant of the first $k$ rows and columns. Negative definiteness requires alternating signs, starting negative. Positive semidefiniteness instead requires every principal minor to be nonnegative, not only the leading ones. A principal minor can choose any common subset of rows and columns.

The matrix $\operatorname{diag}(0,-1)$ exposes the difference. Its leading minors are zero and zero, both nonnegative, yet its quadratic form is $-v^2$, which is negative when $v\ne0$. Checking only leading minors would falsely classify it as positive semidefinite. Symmetric eigenvalue computation is often a more convenient numerical diagnostic, while values close to zero still require tolerance and conditioning judgment.

The form $(u+v)^2$ has matrix $\begin{bmatrix}1&1\\1&1\end{bmatrix}$. Its zero directions satisfy $u=-v$, not $u=v$. Such sign details determine whether a calibration ambiguity is correctly identified. A nonzero vector in the Hessian's null space signals absent quadratic curvature, not automatically a flat objective at higher order.

5. The two-parameter calibration has a complete certificate

Expand the running convex loss:

$$f(u,v)=3u^2-2uv+3v^2-2u-2v+1.$$

The gradient is $(6u-2v-2,\,6v-2u-2)^\top$, and the Hessian is the constant matrix $H=\begin{bmatrix}6&-2\\-2&6\end{bmatrix}$. Solving the two gradient equations gives $u=v=1/2$. The Hessian has eigenvalues 4 along $(1,1)$ and 8 along $(1,-1)$, so it is positive definite.

The residual representation gives a stronger immediate conclusion: $f\ge0$, and both residuals vanish only when $u+v=1$ and $u-v=0$. Hence $(1/2,1/2)$ is the unique global minimizer with loss zero. The two proofs agree for different reasons: positive curvature explains local stability, while the sum-of-squares equality conditions prove global optimality and uniqueness directly.

Since the loss is exactly quadratic, the Taylor relation has no remainder:

$$f(x+h)-f(x)=\nabla f(x)^\top h+\tfrac12h^\top Hh,$$

where $x=(u,v)^\top$. At the optimum, moving by $h$ increases loss by a value between $2\|h\|_2^2$ and $4\|h\|_2^2$. This interprets the eigenvalues as directional error sensitivity. It does not turn parameter sensitivity into a confidence interval; statistical uncertainty would require a model of measurement errors.

6. Convexity turns a local certificate into a global one 42:40

A function on a convex domain is convex if $f(\theta x+(1-\theta)y)\le\theta f(x)+(1-\theta)f(y)$ for every pair of domain points and $0\le\theta\le1$. Strict convexity makes the inequality strict for distinct points and interior weights. The domain must also be convex; checking curvature separately on disconnected pieces is not a replacement.

Suppose a convex function has a local minimizer $x_*$ but there is another domain point $y$ with $f(y)<f(x_*)$. For any small positive $\theta$, the point $(1-\theta)x_*+\theta y$ is feasible and arbitrarily near $x_*$. Convexity gives its value at most $(1-\theta)f(x_*)+\theta f(y)<f(x_*)$, contradicting local minimality. Thus every local minimum of a convex function is global. Strictness is unnecessary for this conclusion.

Strict convexity supplies uniqueness when a minimizer exists. If distinct $x_*,y_*$ were both global minimizers, their midpoint would have a strictly smaller value. But strict convexity does not establish existence: $e^x$ is strictly convex on the real line and has no minimizer. A useful optimization claim must keep existence, globality, and uniqueness as separate statements.

For differentiable convex $f$, the tangent inequality is

$$f(y)\ge f(x)+\nabla f(x)^\top(y-x).$$

It follows by applying the convexity definition along the segment from $x$ to $y$, dividing the chord inequality by its segment parameter, and taking the derivative at zero. If $\nabla f(x_*)=0$, it immediately certifies global minimality. For a twice-differentiable function on an open convex domain, convexity is equivalent to a positive-semidefinite Hessian everywhere. This is an everywhere condition, not a Hessian check at one stationary point.

Boyd and Vandenberghe, §3.1.4, printed p. 71 explicitly distinguish positive-definite Hessians as a sufficient condition for strict convexity from the false converse. The function $x^4$ is strictly convex, yet its second derivative vanishes at zero. Our fourth-order analysis explains why uniqueness and strict growth can persist there despite absent quadratic curvature.

One can see the forward implication by restricting to any line segment. A positive-semidefinite Hessian gives nonnegative second derivative along that segment, hence convexity of the restriction. Positive definiteness makes the directional second derivative strictly positive along every nonconstant segment, which yields strict convexity. These statements assume the required derivatives exist across the segment.

7. Executable diagnostics and their limits

Run the chapter laboratory. It computes the calibration optimum by a linear solve, verifies the Hessian eigenvalues $(4,8)$, compares analytic gradients with central finite differences, and checks the exact quadratic Taylor identity at three distinct parameter vectors. It also checks the scalar double-well classification and the semidefinite leading-minor counterexample.

The finite-difference routine accepts a finite one-dimensional parameter array and a positive finite step. It returns an approximate gradient without changing files or its input. The chosen smooth quadratic makes the central difference exact in real arithmetic, leaving floating-point error as the principal discrepancy. On a general function, truncation error decreases with a smaller step while cancellation error can increase; arbitrary reduction of the step is not a sound verification strategy.

The lab prints calibration optimum=(0.5,0.5), loss=0, Hessian eigenvalues=(4,8). That output checks a specific mathematical construction. It does not establish that a measured calibration objective is globally convex, that finite differences are accurate under observation noise, or that a small reported gradient excludes a remote better solution. These are the boundaries a numerical optimizer must preserve in its status report.

Exercises

  1. Derive the stationary points of $q(x)=(x^2-1)^2$ and classify them locally and globally.
  2. Explain why $|x|$ at zero and $x$ on $[0,1]$ are not counterexamples to the correctly stated first-order necessary condition.
  3. Give a strict minimum, strict maximum, and saddle with the same zero Hessian at the origin. Prove the classifications directly.
  4. Show why the leading principal minors of $\operatorname{diag}(0,-1)$ do not establish positive semidefiniteness. Contrast the positive-definite test.
  5. Derive the two-parameter calibration optimum and prove uniqueness without invoking a numerical solver.
  6. Prove that strict convexity implies at most one minimizer. Give a strictly convex function that does not attain its infimum.
Fully worked solutions

  1. Differentiation gives $q'(x)=4x(x^2-1)$, whose zeros are $-1,0,1$. The second derivative $12x^2-4$ is positive at the outer two and negative at zero. Thus the outer points are strict local minima and zero a strict local maximum. Since $q$ is a square, its value is at least zero everywhere; both outer points attain zero and are global minima. The local maximum is not global because $q(x)$ grows without bound as $|x|$ grows.

  2. The theorem assumes differentiability and an interior minimizer in an open neighborhood. The absolute-value function lacks a derivative at zero. The interval problem has its minimizer at a constrained boundary. Feasible perturbations there are one-sided, so the proof cannot use both positive and negative increments. Each example violates a hypothesis rather than the conclusion of the theorem.

  3. Use $f_1=u^4+v^4$, $f_2=-u^4-v^4$, and $f_3=u^4-v^4$. Each gradient and Hessian vanishes at the origin. Every nonzero point has $f_1>0$, so the origin is a strict global minimum of $f_1$. The sign reverses for $f_2$. For $f_3$, points $(h,0)$ have positive value and points $(0,h)$ negative value for every nonzero $h$, however small; the origin is a saddle. The identical Hessians cannot distinguish the fourth-order behavior.

  4. The leading one-by-one determinant is zero and the full determinant is zero. But the principal minor using only the second row and column is $-1$, and the vector $(0,1)$ gives quadratic form $-1$. Semidefiniteness fails. For a symmetric positive-definite matrix, strict positivity of every leading minor is sufficient and necessary; replacing those strict inequalities by non-strict ones is not a valid semidefinite criterion.

  5. Both squared residuals must vanish to attain zero: $u+v=1$ and $u-v=0$. Adding yields $2u=1$, so $u=v=1/2$. Nonnegativity of both terms proves no smaller value exists, and uniqueness of this linear system proves no other point attains zero. Alternatively, solving the gradient equations gives the same point and the constant positive-definite Hessian establishes strict convexity.

  6. Suppose two distinct minimizing points have the same minimum value $m$. Strict convexity at their midpoint gives a value strictly smaller than $(m+m)/2=m$, a contradiction. This proves at most one minimizer, conditional on existence. The function $e^x$ is strictly convex because its second derivative is positive everywhere. It approaches zero as $x\to-\infty$ but is positive at every finite $x$, so it has no attaining minimizer.

"""Derivative diagnostics checked by finite differences and exact examples."""
import numpy as np


def loss(z):
    u, v = np.asarray(z, float)
    return (u + v - 1) ** 2 + 2 * (u - v) ** 2


def gradient(z):
    u, v = np.asarray(z, float)
    return np.array([6 * u - 2 * v - 2, 6 * v - 2 * u - 2])


def central_gradient(function, point, step=1e-5):
    point = np.asarray(point, float)
    if point.ndim != 1 or not np.isfinite(point).all():
        raise ValueError("a finite one-dimensional parameter array is required")
    if not np.isfinite(step) or step <= 0:
        raise ValueError("step must be finite and positive")
    directions = np.eye(len(point)) * step
    return np.array([(function(point + d) - function(point - d)) / (2 * step)
                     for d in directions])


if __name__ == "__main__":
    hessian = np.array([[6, -2], [-2, 6]], float)
    optimum = np.linalg.solve(hessian, [2, 2])
    assert np.allclose(optimum, [0.5, 0.5])
    assert loss(optimum) == 0
    assert np.allclose(np.linalg.eigvalsh(hessian), [4, 8])
    for point in ([0, 0], [2, -1], [0.3, 0.8]):
        assert np.allclose(central_gradient(loss, point), gradient(point))
        direction = np.array([0.2, -0.1])
        difference = loss(np.array(point) + direction) - loss(point)
        taylor = gradient(point) @ direction + direction @ hessian @ direction / 2
        assert np.isclose(difference, taylor)
    stationary = [-1, 0, 1]
    assert [(x * x - 1) ** 2 for x in stationary] == [0, 1, 0]
    assert [12 * x * x - 4 for x in stationary] == [8, -4, 8]
    bad = np.diag([0.0, -1.0])
    assert bad[0, 0] == 0 and np.linalg.det(bad) == 0
    assert np.linalg.eigvalsh(bad).min() == -1
    # Identical zero Hessians at the origin, three distinct local behaviors.
    epsilon = 0.01
    assert epsilon ** 4 > 0
    assert -epsilon ** 4 < 0
    assert epsilon ** 4 - 0 ** 4 > 0 and 0 ** 4 - epsilon ** 4 < 0
    print("calibration optimum=(0.5,0.5), loss=0, Hessian eigenvalues=(4,8)")
